# Software Quality Engineering Lab Assignments

Course lab submissions for registration number **SE241006**, arranged in numerical order. Each folder contains the files extracted from its corresponding submitted ZIP archive.

| Folder | Assignment | Contents |
| --- | --- | --- |
| [lab01](lab01/) | Software testing fundamentals | Maven calculator and average examples, tests, defect notes, report, and demo code |
| [lab02](lab02/) | Course registration test planning | Test plan, spreadsheet, report, and notes |
| [lab03](lab03/) | Black box testing | Marks test cases spreadsheet and README |
| [lab04](lab04/) | White box testing | Java example, control flow diagram, coverage table, and results |
| [lab05](lab05/) | Unit testing | Maven shopping cart project, JUnit tests, and report |

Open each lab folder for its own instructions and documentation. The Java Maven projects are in `lab01/` and `lab05/`; run `mvn test` from within the relevant folder if Maven and Java are installed.
